# Helicopter AR

D&T lesson: mechanisms in a toy helicopter, with a 3D model students can place on their desk in AR.

## Files
- `index.html` – the lesson page
- `helicopter.glb` – the 3D model
- `model-viewer.min.js` – Google's 3D/AR viewer (v3.5.0, BSD-3 licence)
- `.nojekyll` – tells GitHub Pages to serve the files as they are

## Put it on GitHub Pages
1. Sign in at github.com and click **New repository**. Name it e.g. `helicopter-ar`, set it to **Public**, and create it.
2. Click **uploading an existing file**, drag in all the files from this folder, and click **Commit changes**.
   (`.nojekyll` is hidden on Mac. Press Cmd+Shift+. in Finder to show it. The site works without it.)
3. Go to **Settings → Pages**. Under *Branch*, choose **main** and **/(root)**, then **Save**.
4. Wait 1–2 minutes. Your link appears at the top of that page:
   `https://YOUR-USERNAME.github.io/helicopter-ar/`

## Using AR
Open the link on a phone or iPad (Safari on iPhone/iPad, Chrome on Android) and tap **View on your desk**.
